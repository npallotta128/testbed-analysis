PARAMETER SETTINGS
================================================================================

Sliding Window Clustering:
  - Block Size: 200 timepoints
  - Number of Blocks: 50
  - Sliding Stride: 50 timepoints (50% overlap)
  - Distance Threshold: 40 (hierarchical clustering)
  - Quality Metric: Average Return
  - Quality Threshold: 80th percentile
  - Forward Window: 500 timepoints (for return calculation)
  - Linkage Method: Ward (minimizes within-cluster variance)

Market Cap Calculation:
  - Formula: MarketCap = OutstandingShares × Closing Price
  - Date Approximation: Forward-fill quarterly shares to daily prices
  - Time Series Handling: UTC dates with NaT/NaN handling

KNOWN ISSUES & SOLUTIONS
================================================================================

Issue: Pipeline times out
Solution: Use --nrows parameter
  python integrate_marketcap_protocol.py --nrows 500000

Issue: Memory usage too high
Solution: Restart Python and process in smaller chunks
  python integrate_marketcap_protocol.py --nrows 250000

Issue: Missing market cap for some stocks
Solution: Normal - small-cap stocks lack historical shares data
  Filter with: data = data[data['MarketCap'].notna()]

Issue: Results seem different than expected
Solution: Verify using exact parameters from documentation
